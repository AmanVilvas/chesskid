# ChessKid Lesson Planner — Beginner

A modern, responsive React + Tailwind CSS web application replicating the **ChessKid Lesson Planner (Beginner)** curriculum.

## Features

- **Beginner Curriculum (11 Units)**:
  - Unit 1: Meet the Rook!
  - Unit 2: Meet the Bishops! (Featured with full breakdown & objectives)
  - Unit 3: Meet the Queen!
  - Unit 4: Meet the King!
  - Unit 5: Meet the Pawn!
  - Unit 6: Meet the Knight!
  - Unit 7: Check!
  - Unit 8: Checkmate!
  - Unit 9: Stalemate!
  - Unit 10: Help needed for Checkmate!
  - Unit 11: King & Queen Mate!
- **Interactive Accordion & Desktop Dual-View Modes**:
  - **Desktop Split View**: Left navigation panel of all 11 units with quick status indicators and active orange highlight; right detailed panel with 2-column curriculum breakdown.
  - **Accordion List View**: Full-width collapsible units with smooth transitions.
- **Unit 2 Comprehensive Lesson Plan**:
  - Suggested Time & breakdown (Review, Lesson Video, Discussion) + completion checkbox
  - Description
  - Educational Objectives & Key Learning Objectives (Lines, Measurement, Connections, Comparison, Problem Solving)
  - Review of Previous Unit (Rook's movement)
  - Unit Lessons (Interactive checkboxes with Video & Game icons)
  - Classroom Materials (Supplemental Classroom Activity: Different Diagonals & Worksheet download)
  - Extra Activities (Written Curriculum & Online Chess Glossary)
  - Author attribution (WFM Elizabeth Spiegel)
- **Styling & Icons**:
  - Pixel-perfect recreation of ChessKid green and orange brand palette.
  - Built with Tailwind CSS and Lucide-react icons.

## Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS**
- **Lucide React**

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
